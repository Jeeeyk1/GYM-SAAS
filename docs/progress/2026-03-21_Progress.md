## Decisions Made This Session

### Plan Names
`basic` / `advanced` / `enterprise`
(Legacy DB had `starter` / `growth` / `enterprise` — migrations needed to update CHECK constraints.)

### Branch Scoping Strategy (Option B)
- `org_owner` omits `x-branch-id` — API returns org-wide data.
- `gym_owner` and `staff` MUST send `x-branch-id` — guard rejects without it.
- `member` omits `x-branch-id` — members are org-wide.

### QR Codes and Branches
- Gym QR code (posted at branch entrance): encodes `{ orgSlug, branchId }`. Check-in auto-attributes the branch.
- Member personal QR: if org has multiple branches, member selects branch before generating in the mobile app.

### Plan Limits
Stored in `libs/shared-config/src/plan.limits.ts` as a single constant — so numbers can be changed without touching migrations or service code.

| Plan | maxMembers | maxBranches | aiTokenLimit |
|---|---|---|---|
| basic | 100 | 1 | 0 |
| advanced | 500 | 3 | 100,000 |
| enterprise | unlimited (-1) | unlimited (-1) | 1,000,000 |

### Role Hierarchy

**Platform level** (in `identity.platform_role`):
- `gym_admin` — platform owner + support team. No row in `identity_roles`.

**Gym level** (in `identity_roles`):

| Role | branch_id | Scope |
|---|---|---|
| `org_owner` | NULL | All branches of an org |
| `gym_owner` | specific UUID | One branch only |
| `staff` | specific UUID | One branch only |
| `member` | NULL | Org-wide (can check in at any branch) |

`front_desk` is removed. Replaced by `staff`.
`gym_admin` as a gym-level role is removed — it now exclusively means platform admin.

### Subscription Flow (Manual)
No payment gateway yet. Flow:
1. Gym contacts platform owner.
2. Platform owner creates org via `POST /admin/gyms` (sets plan).
3. Invite email fires to gym owner.
4. Gym owner activates account via `/activate?token=xxx`.
5. Subscription record is auto-created with plan limits from `PLAN_LIMITS`.

### Feature Priority
- **Now:** Core API refactor (org/branch model, role rename, new headers).
- **After API stable:** Announcements, Community chat, AI chat, Goals.
- **After features:** Web dashboard, then Mobile app.
